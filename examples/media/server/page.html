sloth-proxy：web → 服务端 → 内网客户端

页面上的每一个字节都不在服务端，而在内网客户端的本地目录里。服务端只是搬运。

浏览器 → HTTP(:8080 网关) → RPC over TCP(:8991) → 客户端 http.Do → 本地 Handler → 原路返回

上传到内网 分片 POST

选一个文件。大文件也能传——前端会自动切片。
单次请求报文上限 60000 字节（请求走 RPC 入参，受 ag 编码单参数 ≤ 65535 限制）， 所以这里按 48KB 切片逐片上传，客户端按偏移写入同一个文件。 同一条 RPC 通道，上传与下载走的是完全对称的路。
